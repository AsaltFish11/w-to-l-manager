# Windows 移植 Linux 管理器

用 **Rust + egui** 写的桌面工具。它读取项目根目录下的 `project_list.json`，
把里面的「Windows 移植到 Linux」项目列成清单，显示**说明和 GitHub 链接**，
并支持一键**克隆源码 → 安装 / 卸载**。安装卸载的输出显示在界面下方的日志面板里，
同时打印到命令行。
注意: 本项目完全使用AI开发, 且不会长期稳定

## 快速开始

需要 Rust 1.85+，以及 Wayland / X11、OpenGL、fontconfig 等开发库
（Debian / Ubuntu：`sudo apt install libxkbcommon-dev libwayland-dev libx11-dev libgl1-mesa-dev libfontconfig1-dev`）。

```bash
cargo run --release
```

把 `project_list.json` 放在项目根目录即可；也可以用环境变量 `W2L_PROJECT_LIST` 指定路径。

## 怎么用

- **列表**：每个项目显示说明、作者、适用平台、GitHub / B 站链接（点击用系统默认浏览器打开）、
  作者的额外提示、依赖和「已安装 / 未安装」状态。
- **卸载**：默认和非 0 中止。装在不同层次（用户级 / 系统级、不同 PREFIX）时
  「没东西可卸」返回非 0 是正常的，给那条命令单独加 `"ignore-error": true` 就会失败也继续，
  整体仍算卸载完成（日志里用琥珀色标出，不会当成失败）。
- **操作按钮**：`project_list.json` 里可以用 `button-1`、`button-2` … 定义按钮
  （数字任意大小都认），点一下会先确认再执行它自己的 `commands`。
  按钮可以写 `"background": true`：这类按钮丢到后台跑，不占用任务位也不会卡住界面，
  只在开始和结束时各提示一句，期间随你怎么用（启动 GUI 程序那种不会退出的命令就该这么写）。
- **更新列表**：从配置仓库 `https://github.com/AsaltFish11/w-to-l-manager-config.git`
  浅克隆到临时目录 `tmp/`，把里面的 `project_list.json` 取到项目根目录，然后清掉 `tmp/`。
  可以点「立即更新」手动拉，也可以勾选「启动自动更新」（**默认开启**）让程序每次启动
  后台检查一次；更新失败不影响使用，继续用当前列表。需要系统里有 `git` 和网络。
  注意：**更新会覆盖项目根目录下的 `project_list.json`**（本地改动会被仓库版本替换）。
- **安装**：先检查依赖 —— 缺依赖时会问你是自动安装（用系统的 pacman / apt）还是手动安装；
  然后把源码克隆到 `sources/<项目 id>/`，在该仓库根目录里执行安装命令。
  克隆成功后会写一个 `.w2l-clone-ok` 标记文件；下次安装只认这个标记，
  没有标记就当作上次没克隆完，**删掉整个目录重新克隆**。
- **卸载**：只执行 JSON 里写好的 `uninstall-commands`，**不做任何推导**（没写就装不了也卸不了）；
  执行前会列出将要运行的命令，并询问是否一并移除「由本管理器装过的依赖」和克隆的源码目录
  （默认都保留）；安装前就已存在的依赖永远不会被动。
- **sudo 密码**：只有执行到需要 root 的命令时才弹窗询问，密码只保存在内存中，退出即消失。
- **日志**：下方面板显示本次会话的完整输出，可滚动、可触摸滑动，同时也会打印到命令行。
  慢命令会每 10 秒报一次「仍在执行… 已耗时 N 秒」，每步和整个任务结束时也会显示耗时，
  所以国内克隆仓库那种几分钟的操作，能一眼看出是在慢慢跑而不是卡死
  （界面标题旁也会显示「已耗时 N 分 N 秒」）。

## 设置

右上角「设置」里有：

- **更新**：启动时是否自动更新列表、配置仓库地址、手动「立即更新」。
- **执行**：命令的工作目录，以及**命令环境变量** —— 这里配的变量会在每条命令执行前先导出
  （root 命令同样生效，因为是以 `export` 前缀写进命令里的）。
- **位置**：项目目录、状态文件、日志文件的路径（只读，方便排查）。

设置保存在状态文件里，关闭设置窗口时写入。

## 文件位置

| 内容 | 位置 |
| --- | --- |
| 源码 | `sources/<项目 id>/`（项目根目录下，每个项目独立） |
| 临时目录 | `tmp/`（更新时克隆到这里，用完即删） |
| 安装状态 | `~/.local/share/w-to-l-manager/state.json`（可用 `W2L_STATE_FILE` 改；也记着上次用的列表路径和自动更新开关） |
| 日志 | `~/.local/state/w-to-l-manager/w-to-l-manager.log`（`W2L_LOG=debug` 记录更详细） |
